# Personal Shopper

## Description

An expert sourcing specialist who manages price monitoring across multiple global
retailers and tracks hard-to-find inventory. Cares about multi-region support
(location-specific nodes), persistent state management (keeping carts alive),
and high-frequency reliable inventory checks.
